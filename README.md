# IEM CSE-AI/ML Event Registration

Frontend website for college events organized by the CSE-AI/ML department of Institute of Engineering & Management.

## Events
- Hackathon
- Quiz
- Photography
- Stand-up Comedy
- Go As You Like
- Chess
- Breadboard Design

## Run locally
Open index.html in a browser, or use VS Code Live Server.

## GitHub Pages
Enable GitHub Pages from Settings → Pages and deploy the main branch from the root folder.

> Note: The registration form is currently frontend-only. It does not store submissions in a database.
